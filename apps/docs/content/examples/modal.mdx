## How the Example Works

The Modal example demonstrates how to implement a floating chat interface using the `AssistantModal` component. This component provides a persistent chat button that transforms into a modal dialog when activated.

### Component Overview

The `AssistantModal` component creates a floating chat interface with the following key features:

- **Floating Button**: A circular button positioned in the bottom-right corner of the screen
- **State Transitions**: Smooth animations between open and closed states
- **Modal Dialog**: A fixed-size modal that appears when the button is clicked
- **Thread Integration**: Built-in chat functionality using the `Thread` component

### Floating Button Behavior

The floating button provides visual feedback through icon transitions and tooltip changes:

- **Closed State**: Shows a `BotIcon` with "Open Assistant" tooltip
- **Open State**: Shows a `ChevronDownIcon` with "Close Assistant" tooltip
- **Animations**: Smooth scale and rotation transitions between states
- **Hover Effects**: Button scales up on hover and down on click

### Modal Positioning and Animations

The modal is positioned using a fixed anchor point in the bottom-right corner:

- **Position**: Fixed at `right-4 bottom-4` (16px from edges)
- **Size**: Fixed dimensions of `h-[500px] w-[400px]`
- **Z-Index**: `z-50` to ensure it appears above other content
- **Animations**: Fade, slide, and zoom effects for smooth open/close transitions

### Thread Component Integration

The `Thread` component is integrated within the modal content to provide chat functionality:

- **Background**: Inherits modal background styling
- **Layout**: Full-width within the modal container
- **Functionality**: Complete chat interface with message display and composer
- **Responsive**: Adapts to the modal's fixed dimensions

## What API is Being Used

The Modal example uses the `AssistantModalPrimitive` API, which provides composable primitives for building modal interfaces.

### AssistantModalPrimitive Components

The `AssistantModalPrimitive` provides four main components:

#### Root Component

The root component manages the overall modal state and provides context to child components:

```tsx
<AssistantModalPrimitive.Root>
  {/* Child components */}
</AssistantModalPrimitive.Root>
```

#### Anchor Component

The anchor component defines the positioning reference point for the modal:

```tsx
<AssistantModalPrimitive.Anchor className="fixed bottom-4 right-4 size-11">
  {/* Trigger button */}
</AssistantModalPrimitive.Anchor>
```

**Key Props:**

- `className`: CSS classes for positioning and sizing
- `sideOffset`: Distance from the anchor point (default: 16px)

#### Trigger Component

The trigger component wraps the button that opens and closes the modal:

```tsx
<AssistantModalPrimitive.Trigger asChild>
  <AssistantModalButton />
</AssistantModalPrimitive.Trigger>
```

**Key Props:**

- `asChild`: Renders the trigger as a child component instead of a button

#### Content Component

The content component defines the modal dialog that appears when opened:

```tsx
<AssistantModalPrimitive.Content
  sideOffset={16}
  className="bg-popover text-popover-foreground data-[state=closed]:animate-out data-[state=closed]:fade-out-0 data-[state=closed]:slide-out-to-bottom-1/2 data-[state=closed]:slide-out-to-right-1/2 data-[state=closed]:zoom-out data-[state=open]:animate-in data-[state=open]:fade-in-0 data-[state=open]:slide-in-from-bottom-1/2 data-[state=open]:slide-in-from-right-1/2 data-[state=open]:zoom-in z-50 h-[500px] w-[400px] overflow-clip rounded-xl border p-0 shadow-md outline-none"
>
  <Thread />
</AssistantModalPrimitive.Content>
```

**Key Props:**

- `sideOffset`: Distance from the anchor point
- `className`: CSS classes for styling and animations
- `data-state`: Automatically managed open/closed state

### Complete Implementation Example

Here's the complete implementation showing how all components work together:

```tsx
import { AssistantModalPrimitive } from "@assistant-ui/react";
import { Thread } from "@/components/assistant-ui/thread";

export const AssistantModal = () => {
  return (
    <AssistantModalPrimitive.Root>
      <AssistantModalPrimitive.Anchor className="fixed bottom-4 right-4 size-11">
        <AssistantModalPrimitive.Trigger asChild>
          <AssistantModalButton />
        </AssistantModalPrimitive.Trigger>
      </AssistantModalPrimitive.Anchor>
      <AssistantModalPrimitive.Content
        sideOffset={16}
        className="bg-popover text-popover-foreground data-[state=closed]:animate-out data-[state=closed]:fade-out-0 data-[state=closed]:slide-out-to-bottom-1/2 data-[state=closed]:slide-out-to-right-1/2 data-[state=closed]:zoom-out data-[state=open]:animate-in data-[state=open]:fade-in-0 data-[state=open]:slide-in-from-bottom-1/2 data-[state=open]:slide-in-from-right-1/2 data-[state=open]:zoom-in z-50 h-[500px] w-[400px] overflow-clip rounded-xl border p-0 shadow-md outline-none"
      >
        <Thread />
      </AssistantModalPrimitive.Content>
    </AssistantModalPrimitive.Root>
  );
};
```

## Accessibility and Mobile Guidance

### Mobile Device Compatibility

The Modal example is designed to work seamlessly across all device types:

- **Touch Interactions**: The floating button responds to touch events with appropriate feedback
- **Responsive Sizing**: Modal dimensions adapt to different screen sizes
- **Viewport Considerations**: Fixed positioning ensures the button remains accessible
- **Performance**: Optimized animations for smooth performance on mobile devices

### Keyboard Navigation

The component supports full keyboard navigation:

- **Tab Navigation**: Users can tab to the floating button
- **Enter/Space Activation**: Standard button activation methods
- **Escape Key**: Closes the modal when open
- **Focus Management**: Proper focus handling when opening/closing the modal

### Screen Reader Support

The implementation includes comprehensive screen reader support:

- **Semantic HTML**: Uses proper button elements and ARIA attributes
- **State Announcements**: Screen readers announce open/closed states
- **Tooltip Descriptions**: Clear descriptions for both open and closed states
- **Hidden Text**: Screen reader-only text for additional context

</Callout>
